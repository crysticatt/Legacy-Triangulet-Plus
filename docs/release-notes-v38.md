## Triangulet Opener v38

**New**
- **Keep PC awake**: while opening, Windows (and Mac) will not go to sleep, but the screen can turn off. Leave a game running AFK and switch the monitor off. Turn it off in Settings.
- **Updates install by themselves** by default (while the window is hidden). Turn it off in Settings.

**Fixed**
- Trian pictures not loading when you scroll the list while opening fast: they now use their own connections and load a few screens ahead.
- Update problems are now written to `opener.log` so they can be diagnosed.
- Turning on "Before sign-in" now explains that antivirus may flag an unsigned app, and how to report it to Microsoft.

**Downloads**
- Windows: `TrianguletOpener-Setup-v38.exe` (installer) or `TrianguletOpener-v38.exe` (portable)
- Mac: `TrianguletOpener-Mac-v38.zip`
