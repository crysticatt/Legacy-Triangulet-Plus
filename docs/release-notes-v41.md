## Triangulet Opener v41

**New**
- **Least mode**: the workers go for the trian you own the fewest of (a missing trian counts as 0). If several are tied, one is picked at random and kept until it is no longer tied.
- **Wishlist tab**: click trians to star them. You get an alert the first time a starred trian drops.
- **Wish mode**: like Least, but only among your starred trians.
- The Mode buttons are now Fixed / Next / Hunt / Least / Wish.

**Fixed**
- Mac dashboard: v40 had a typo that stopped the whole page from loading. If you are on Mac and v40 shows an empty page, update to v41.

**Download**: Windows `TrianguletOpener-Setup-v41.exe`, Mac `TrianguletOpener-Mac-v41.zip`.
