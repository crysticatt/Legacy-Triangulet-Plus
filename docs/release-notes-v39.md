## Triangulet Opener v39

**New**
- **Hourly summary**: each hour a notification (plus ntfy and the Discord webhook, if set up) says how many packs you opened, how many Mystical and Chroma, and how your coins changed. Turn it off in Settings.

**Changed**
- **Smoother opening, no waves**: the work done for each pull (counters, log, history) no longer holds up the next request, and the delay is now spaced per lane instead of on a shared clock. Requests keep flowing instead of going out in bursts of about 40 with a pause between.

**Downloads**
- Windows: `TrianguletOpener-Setup-v39.exe` (installer) or `TrianguletOpener-v39.exe` (portable)
- Mac: `TrianguletOpener-Mac-v39.zip`
